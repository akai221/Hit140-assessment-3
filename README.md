# HIT140 Assessment 3 - Linear Regression 2.1 (goal difference)

- `wrangle_2_1.py` builds the 2.1 dataset from the `input_*.csv` files (run it in the same folder).
- `LR_2.1_dataset_clean.csv`: 104 rows, 8 explanatory variables, response = goal_difference.
- `LR_2.1_data_dictionary.csv`: definition, source and caveats for every column.
- `source_verification.csv`: checks against fifa.com, FBref, Transfermarkt and The Stats Don't Lie (opens in Excel).
- `input_*.csv`: the source files the script reads.
